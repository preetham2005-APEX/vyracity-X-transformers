## Key facts for integration (full detail in MANIFEST.md)

- Maps per atlas: `_BC` (RGBA sRGB: albedo + coverage alpha), `_N` (RGB raw, OpenGL +Y up),
  `_MS` (RGBA raw: R metallic = 0, G AO, B height with 0.5 = road plane ±20 mm, **A smoothness**).
  Material must use **Smoothness Source = Metallic Alpha**; `_N` as Normal Map; `_MS` sRGB off.
- Every atlas cell has a real **world size** — drive the decal projector from it.
  `T_RW_LaneWear` cells are **1.0 m across × 4.0 m along** (non-square); the rest are square.
- Alpha fades to exactly 0 on every cell border (QA enforces it), so no decal rectangles.
- All five meshes are driven over: each carries a **flush non-convex `COL_` plate**, collider top
  ≤ +10 mm above the road plane. QA fails the build if any collider exceeds the CLAUDE.md 0.05 m
  step rule. The grate collider deliberately ignores the bars so wheels cannot drop in.
- New material name `VC_Joint_Sealant` (registered at runtime, Infra/ not edited) needs a
  VeyraMaterialLibrary entry alongside the Infra names.

- **Collider names** now `COL_<surface>_<name>`.

## A QA metric that was wrong, and how

The tiling seam test first failed `T_SW_Concrete_Panel_MS`. It was the TEST, not the texture: it
compared the wrap step against the MEAN interior difference, which is dominated by flat areas, so
any texture with hard regular features fails. Measured properly, the wrap step (6.4) sits inside
the range of the texture's own interior panel joints (3.5-9.0) and the row wrap is smaller than
every interior row joint. The metric now compares the wrap against the texture's own worst
internal transition, like for like. Self-tested: a non-tiling 0-255 gradient scores 255.0 against
a 1.25 threshold, so it still has teeth; the footway scores 0.71.
