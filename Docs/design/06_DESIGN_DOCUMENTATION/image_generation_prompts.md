# Image-Generation Prompts (images NOT generated in this session)

No AI image-generation tool was available in this session, so the 22 concept images in folders 02–05 were **not generated**. No placeholder or fake image files were created. Each prompt below is ready for an image model. The **composition reference** column points to a real render in this package taken from the same camera, so the generated image stays faithful to the validated geography.

**Shared style preamble (prepend to every prompt):**

> Photorealistic AAA open-world racing game screenshot, Unity HDRP-quality look adapted for premium mobile, physically based materials, believable modern coastal city with subtle near-future architecture (not cyberpunk), realistic proportions, natural colour grading, 16:9, 3840x2160. World: VEYRA CITY (fictional). Road markings: white lane/edge lines, yellow lines separating opposing traffic. Fictional car brands only, no real logos or badges.

**Shared negative prompt:**

> cartoon, toon shading, oversaturated neon everywhere, cyberpunk megastructures, flying cars, holograms, floating roads, impossible junctions, empty lifeless streets, identical repeating buildings, real car brands or logos, text artifacts, watermark, collage, split screen
